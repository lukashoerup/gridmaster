> I have this idea of building a game I have earlier dubbed "Gridmaster". Not
> sure if that is the ideal name, but just for reference. Now this game is
> basically a simultor game. A renewable tycoon type game, where the idea is to
> build your energy empire using renewables. My initial atempt at it did not go
> well enough as AI models back then were not capable enough to actually build
> this game. So I want to try again.
>
> THe idea is that you start very small. You buy a few solar panels, and then
> you start earning money on them. Then you can build some wind mills,
> batteries later on as price fluctuations become more extreme, to optimize
> based on energy prices, invest in optimizations and build more and bigger
> projects, such as a nuclear plants, hydro plants, etc. And then maybe even
> later moore experimental stuff, such as cryo energy storage, wave energy
> generation units, power to x, etc. In my first attempt I found it very hard to
> actually model energy prices, weather, etc. so I actually ended up using real
> data. It could be fun, but I am thinking the game should begin in the 1990s.
> or similar, so there is a historical progression as well.
>
> There should be some geography involved, so that the player can mitigate
> risks/tap into different markets. It should be in Europe I think, because the
> markets there are quite diverse as well as weather patterns etc.
>
> Now, I want this to be a steam game at some point. At least that was the
> idea. It shoudl be fun, casual but also realistic. Not too easy, as I want to
> target a more mature audience. At least that was my idea. But perhaps lets
> start out to research other similar games to pinpoint target audience and how
> we can create this game to make it fun, and figure out the optimal playstyle.
> Also see if there are any other similar games so we can learn from them.
>
> Now if you have any other suggestions as to how we should start, we can do
> that. I want a new repo for this game. If you have any additional ideas as to
> how we should approach this initially, let me know. Lets begin.
